# 🚀 Release v2.0 - Sistema APPD Base

> **Data de Lançamento:** 21/10/2024  
> **Tipo:** Release Inicial  
> **Status:** ✅ Estável

---

## 📋 Visão Geral

A **versão 2.0** marca o lançamento oficial do Sistema APPD (Associação de Pais e Pessoas com Deficiência), uma plataforma completa desenvolvida com **Laravel 10** e **Filament 3** para gestão de associados, atendimentos, vagas de emprego e talentos.

---

## 🎯 Principais Módulos

### 👥 **Gestão de Associados**

Sistema completo para cadastro e gerenciamento de associados da APPD.

**Recursos:**

-   ✅ Cadastro completo de associados (pessoas físicas)
-   ✅ Gestão de carteirinhas de identificação
-   ✅ Vínculo com benefícios sociais
-   ✅ Registro de deficiências e CID-10
-   ✅ Gestão de talentos e habilidades
-   ✅ Upload de fotos e documentos
-   ✅ Histórico de alterações (versionamento)
-   ✅ Filtros básicos (status, idade, cidade, sexo)

**Campos Principais:**

-   Dados pessoais (nome, CPF, RG, data de nascimento)
-   Endereço completo (CEP, logradouro, bairro, cidade, UF)
-   Contatos (telefone, WhatsApp, e-mail)
-   Dados sociodemográficos (raça, religião, escolaridade, ocupação)
-   Informações de deficiência (tipo, causa, aparelhos, CID-10, CRM)
-   Declaração sexual e estado civil
-   Status (ativo/inativo)

---

### 📋 **Gestão de Atendimentos**

Registro e acompanhamento de atendimentos realizados.

**Recursos:**

-   ✅ Registro de atendimentos para associados e não-associados
-   ✅ Múltiplos tipos de atendimento
-   ✅ Geração de declarações de comparecimento
-   ✅ Histórico completo de atendimentos
-   ✅ Filtros por pessoa, tipo e data
-   ✅ Observações e anotações

**Tipos de Atendimento:**

-   Orientação jurídica
-   Assistência social
-   Psicologia
-   Fisioterapia
-   Encaminhamento para vagas
-   Outros serviços

---

### 💼 **Gestão de Vagas e Talentos**

Sistema de intermediação de mão de obra.

**Recursos:**

-   ✅ Cadastro de vagas de emprego
-   ✅ Banco de talentos dos associados
-   ✅ Encaminhamento de candidatos para vagas
-   ✅ Acompanhamento de status
-   ✅ Registro de empresas parceiras
-   ✅ Filtros por área, requisitos e localização

**Campos de Vagas:**

-   Título e descrição
-   Empresa/empregador
-   Requisitos e qualificações
-   Salário e benefícios
-   Localização
-   Status (aberta/fechada)

---

### 🎁 **Gestão de Benefícios**

Controle de benefícios sociais vinculados aos associados.

**Recursos:**

-   ✅ Cadastro de tipos de benefícios
-   ✅ Vínculo many-to-many com associados
-   ✅ Histórico de benefícios por associado
-   ✅ Relatórios de beneficiários

**Exemplos de Benefícios:**

-   Cesta básica
-   Vale-transporte
-   Auxílio-alimentação
-   Medicamentos
-   Fraldas geriátricas
-   Outros auxílios

---

### 🎫 **Sistema de Carteirinhas**

Emissão e controle de carteirinhas de identificação.

**Recursos:**

-   ✅ Geração de carteirinhas com foto
-   ✅ Controle de validade
-   ✅ Renovação automática
-   ✅ Histórico de emissões
-   ✅ Filtro de carteirinhas a vencer

-   Composer 2.x
-   Node.js 18+
-   NPM/Yarn

### **Instalação:**

```bash
# Clone o repositório
git clone [repo-url]

# Instale dependências
composer install
npm install

# Configure ambiente
cp .env.example .env
php artisan key:generate

# Execute migrations
php artisan migrate --seed

# Build assets
npm run build

# Inicie servidor
php artisan serve
```
